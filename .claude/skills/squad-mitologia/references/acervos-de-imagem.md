# Acervos de referência visual

Referência visual para o guia de estilo e para os character sheets vem **apenas de acervo de
domínio público/CC0 documentado**. Registrar no guia de estilo: obra, acervo, licença, link.

## Prioridade 1 — CC0 com API
- **Met Museum Open Access** — https://metmuseum.github.io/ — 400k+ obras CC0, API sem
  chave. Busca: `https://collectionapi.metmuseum.org/public/collection/v1/search?q=<termo>&hasImages=true`.
  Forte em Grécia (cerâmica), Egito, Mesopotâmia.
- **Smithsonian Open Access** — https://www.si.edu/openaccess — 4,5M itens CC0.
- **Rijksmuseum** — https://data.rijksmuseum.nl/ — ~800k imagens hi-res CC0 (chave gratuita).

## Prioridade 2 — agregador
- **Wikimedia Commons** — melhor cobertura para arte egípcia, mesopotâmica, nórdica
  (pedras rúnicas, entalhes) e indígena brasileira (grafismo, cerâmica marajoara).
  Checar a licença item a item.

## Cuidado
- **British Museum**: majoritariamente CC BY-NC-SA — serve como estudo, **não** como asset.
- Obra de Alphonse Mucha: morto em 1939 — obra em domínio público na maior parte do mundo;
  usar como referência de estilo é seguro.

## O que buscar por cultura (semente para o historiador de arte)
| Mitologia | Linguagem visual de partida |
|---|---|
| Grega | Cerâmica de figuras vermelhas/negras, frisos, meandros |
| Nórdica | Entrelaçados (estilos Urnes/Borre), pedras rúnicas, madeira entalhada |
| Egípcia | Pintura tumular: perfil composto, paleta ocre/lápis-lazúli, hieróglifos |
| Mesopotâmica | Relevos assírios, selos cilíndricos, lamassu |
| Hindu | Miniaturas (Pahari/Mughal), bronzes Chola, mandalas |
| Brasileira | Grafismo indígena (povo específico!), cerâmica marajoara, xilogravura de cordel |
